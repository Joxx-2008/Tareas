# TAREA - Mini Proyecto: 
 Este programa realizado en C++ imita una tienda de ropa llamada VIPER que realizar diferentes operaciones, como registrar productos,
 visualizar los productos registrados, buscar un producto por su nombre, generar reportes y controlar el stock bajo.

 Para almacenar la informacion utilizamos tres arreglos unidimensionales uno para los nombres, otro para los precios y otro para las
 cantidades disponibles.

 El programa está organizado mediante funciones, lo que permite dividir las operaciones y mantener el código más ordenado. También
 utilizamos estructuras condicionales como if y switch, y ciclos como for y do while para recorrer los arreglos y mantener el menú 
 funcionando hasta que el usuario decida salir.
También desarrollamos un reporte que calcula el total de unidades disponibles y el valor económico del inventario. Como característica 
creativa, incorporamos una alerta que identifica los productos que tienen tres unidades o menos, permitiendo reconocer cuándo es necesario 
reabasteserlo.
